# StudyBro

## Overview

The Smart Peer-to-Peer Learning Platform aims to revolutionize traditional education methods by integrating digital tools for a more flexible, accessible, and personalized learning experience. By fostering collaboration, resource sharing, and efficient time management, the platform enables students to maximize their learning potential through innovative features.

## Project Status

> **Note**: This project is still under development. Currently, only the **Notes Sharing** and **Chatbot** features are available, with additional features planned for future releases.

## Problem Statement

Despite the rise of online courses and digital education tools, many educational institutions still rely heavily on traditional, in-person instruction. This limits the potential of technology to create more adaptive, engaging, and accessible learning experiences. Our platform addresses this challenge by providing a peer-to-peer learning solution that enhances classroom education and makes learning fun and flexible.

## Project Goals

Our platform is designed to:
1. Embrace efficiency in learning.
2. Enable resource organization.
3. Boost productivity and time management.
4. Empower users to take charge of their academic success.
5. Unlock the full potential of collaborative learning.

## Key Features

- **Resource Organization**: Structured storage and categorization of study resources.
- **Progress Tracking**: Monitor learning progress and stay on top of goals.
- **Collaborative Learning**: Connect with peers and study groups for a supportive learning environment.
- **Time Management & Study Goals**: Tools to manage time effectively and set clear learning objectives.
- **Contests and Gamified Learning**: Engage in educational contests and gain rewards for progress.
- **Chatbot Assistance**: AI-driven support for answering queries and guiding users.
- **Note Sharing**: Seniors can share subject notes with juniors, and students can post notes for batchmates who missed classes.

## Unique Aspects

The platform uniquely allows seniors to provide notes for juniors and offers students the ability to share class notes with peers who could not attend lectures, promoting a collaborative and inclusive learning environment.

## Technologies

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express.js
- **Database**: PostgreSQL
- **Machine Learning**: Python (for chatbot functionality)

## Usage

1. **Sign Up**: Create an account to join the learning community.
2. **Connect**: Link up with peers and start organizing your study resources.
3. **Collaborate**: Share notes, engage in group discussions, and track progress.
4. **Compete**: Participate in contests and gamified learning activities.
5. **Track**: Use the platform’s progress tracking and goal-setting features to stay focused.

# How to Run the Project
Follow these steps to clone the repository and run the StudyBro:

## Steps to Start

1. Clone this repository:
   ```bash
   git clone https://github.com/AbhinavKaintura/StudyBro.git
2. Navigate to the Project Directory: Change into the project directory:
   ```bash
   cd StudyBro
3. Install the required dependencies

You can install the dependencies using npm. Here’s the command to install them:

   ```bash
   npm install
```
4. Run the index file
   ```bash
   nodemon index.js
5. The frontend will load and the website is good to run on [localhost:3000](http://localhost:3000)
